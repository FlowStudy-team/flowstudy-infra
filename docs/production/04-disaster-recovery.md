# 灾难恢复

| 故障 | 用户影响 | 检测方式 | 临时处置 | 恢复步骤 | 数据一致性风险 | 当前自动恢复 |
|---|---|---|---|---|---|---|
| 数据库不可用 | 登录、内容、提交、文档均不可用或异常 | Core/Judge DB 连接日志、健康检查 | 暂停写入和提交 | 恢复 MySQL、校验数据、重启 Core/Judge | 高，提交和结果可能不一致 | 未发现 |
| RabbitMQ 不可用 | 代码运行/提交无法进入判题 | Core RabbitMQ 异常、队列监控 | 暂停提交或返回系统繁忙 | 恢复 MQ、确认 queue、重放待判任务 | 中，Core 已入库但未投递可能丢任务 | Core publish 异常会抛错，补偿未发现 |
| Redis 不可用 | 当前影响未知 | Redis 连接日志 | 若仅限流可降级 | 恢复 Redis | 待确认 | 未发现 Redis 实现 |
| Judge 服务不可用 | 提交保持 PENDING，结果不更新 | RabbitMQ 堆积、Judge 进程日志 | 提示判题延迟 | 恢复 isolate/Worker，消费积压 | 中，重复消费需幂等 | DB 更新失败 NACK，进程管理未发现 |
| AI 服务不可用 | AI 侧边栏不可用 | `/health`、前端 AI 错误 | 前端提示 AI 不可用 | 恢复 AI 和模型密钥 | 低，不影响核心学习/判题 | 未发现自动降级外的业务保障 |
| Core 服务不可用 | API 全部不可用 | HTTP 健康检查、日志 | Nginx 返回维护页 | 恢复 Core、验证 DB/MQ | 高 | 未发现 |
| 前端或 Nginx 不可用 | 用户无法访问页面或 API 代理 | Nginx 日志、HTTP 检查 | 直连 API 排查 | 恢复 Nginx 配置和前端 dist | 低到中 | 未发现 |
| 磁盘空间不足 | MySQL/RabbitMQ/Judge 临时文件失败 | 磁盘监控 | 停止大任务、清理日志和临时文件 | 扩容、恢复服务 | 高 | 未发现告警 |
| 日志爆满 | 服务写日志失败或磁盘满 | 磁盘和日志检查 | 归档/清理日志 | 配置 logrotate/采集 | 中 | 未发现 |
| 服务反复重启 | 用户请求不稳定，判题中断 | 进程/容器重启计数 | 暂停流量，保留现场 | 查看最近配置和日志，回滚 | 中 | compose/进程守护未落地 |
